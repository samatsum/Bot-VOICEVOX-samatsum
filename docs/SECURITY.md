# セキュリティ

## 秘密情報

以下はパスワード同等です。

- Discord Bot Token
- Turso Auth Token
- `.env`

公開リポジトリへcommitしないでください。

## 誤公開した場合

チャット、Issue、コミット、スクリーンショット等へTokenを出した場合は、そのTokenを「漏洩済み」と扱い、即座に失効・再発行してください。

Git履歴から文字列を消しただけでは、既に取得されたTokenは安全になりません。必ずToken自体をローテーションしてください。

## 最小権限

Bot自身へDiscordの`管理者`権限を付与しないことを推奨します。必要な個別権限だけを付与してください。

## `/speak message`

過去メッセージ読み上げでは、実行者が元チャンネルを閲覧できるか確認し、Bot権限を使った情報漏洩を防ぎます。

## Import

辞書Importは外部JSONを入力として受け取ります。初版では信頼できるファイルを使用してください。Release Candidateの最終試験では巨大/不正JSONでBotがクラッシュしないことも確認してください。
